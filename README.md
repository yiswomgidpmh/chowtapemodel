## Overview

ChowTapeModel is an open-source tape machine emulation plugin based on physical modeling of magnetic hysteresis, offering authentic wow, flutter, and saturation from classic reel-to-reel machines.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ChowTapeModel** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Hysteresis Model** | Physically accurate magnetic hysteresis based on the Jiles-Atherton model |
| **Wow and Flutter** | Independently adjustable wow, flutter, and speed drift per instance |
| **Tone Control** | Treble loss, bias, and noise controls matching vintage machine behavior |
| **Open Source** | Fully open-source with active development on GitHub |
